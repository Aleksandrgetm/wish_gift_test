# Project Stack

- Laravel
- PHP 8.4+
- Vue 3
- Vuetify 3
- Vite

# Backend

- Use FormRequest validation.
- Keep controllers thin.
- Put business logic into Services.
- Follow PSR-12.

# Frontend

- Use Vue 3 Composition API.
- Use <script setup>.
- Use Vuetify components whenever possible.
- Avoid inline styles.

# Database

- Use Eloquent relationships.
- Prefer eager loading.
- Create migrations for schema changes.

# UI

- Follow Material Design 3.
- Mobile-first.
- Responsive layouts.

# Before finishing

- Check imports.
- Run formatting.
- Don't break existing functionality.
